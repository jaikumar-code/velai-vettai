# Optional modes (ideas adapted from career-ops)

Only run when the user asks.

- **outreach**: a 200-character connection note and a short follow-up for a named recruiter or hiring manager. Honest, specific, no flattery. The user sends it.
- **research**: company snapshot from public pages: product, size, recent news, tech stack from job posts.
- **stories**: build a bank of 6-8 reusable STAR+R interview stories from the real resume. Never fabricate outcomes or numbers.
- **negotiate**: talking points for salary, notice period buy-out, location. Based on the user's stated numbers only.
